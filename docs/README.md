# Documentación del Proyecto

Este proyecto sigue la estructura base recomendada para entregas del curso. La documentación complementaria se encuentra en los archivos de esta carpeta y el código principal en `src/`.

## Estructura general

- `src/`: código fuente principal
- `docs/`: documentación técnica y de instalación
- `notebooks/`: experimentación y análisis exploratorio
- `experiments/`: artefactos y resultados de experimentos
- `tests/`: pruebas automatizadas

## Cómo empezar

1. Crear un entorno virtual o conda.
2. Instalar dependencias desde `requirements.txt`.
3. Ejecutar el punto de entrada principal en `src/main.py`.
