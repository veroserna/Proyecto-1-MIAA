# Documentación de la API

Este proyecto no define una API REST por defecto. Si en futuras entregas se expone un servicio, esta documentación debe describir:

- endpoints disponibles
- métodos HTTP
- cuerpos de entrada
- respuestas esperadas
- ejemplos de consumo

## Estado actual

La estructura base está preparada para un proyecto de análisis o aprendizaje automático, y puede ampliarse según el caso de uso.
